# FedRAMP 20x Class A Linear template

This portable resource contains seven milestones and 51 issues: eight parent issues and 43 sub-issues. The three rule checklists cover 23 mandatory, 11 recommended, and nine optional Class A rules.

- `template.json` is the editable version-1 portable export.
- `CONTENTS.html` is a complete, local preview of the content.
- `SHA256SUMS` verifies these resource files.

The content was exported from the saved Linear project template on October 16, 2026. It preserves milestone assignments, 209 checkboxes, one response-target table, and public FedRAMP source links. Organization IDs, source issue identifiers, assignees, cycles, fixed dates, and the source initiative are excluded. Internal Linear and local fragment links were converted to text.

Use the [Linear template importer](../../../../../tools/linear-template/README.md) to create a reusable template in another organization. From the repository root:

```sh
python3 tools/linear-template/import_template.py preview \
  --file resources/fedramp/20x/class-a/linear/template.json
```

The shareable package is [dist/linear-fedramp-class-a.zip](../../../../../dist/linear-fedramp-class-a.zip).

Review current source requirements and applicability before using this work plan. Completion does not establish that FedRAMP certification has been awarded. This export does not include original project documents, comments, history, or issue relationship edges beyond parent/sub-issue relationships.
