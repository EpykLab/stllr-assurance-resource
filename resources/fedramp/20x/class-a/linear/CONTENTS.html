FedRAMP 20x Class A

Portable content preview · exported October 16, 2026 · 7 milestones · 51 issues · 43 sub-issues

Reusable work plan based on the FedRAMP 20x Class A project, with seven readiness milestones and 51 issues, including mandatory, recommended, and optional rule checklists.

Before starting, review current FedRAMP requirements and Class A applicability, set project and milestone dates, and assign owners. Source rule references were reviewed on October 16, 2026. Completion of this work plan does not itself mean FedRAMP certification has been awarded.

Milestones

1. Scope and certification approach agreed

Define the offering boundary, resource inventory, certification type, and Rev5/20x applicability decisions.

Exit: scope and inventory are reviewed; the 20x Program approach is recorded; the Rev5 maintenance applicability question has a documented disposition.

2. Core security controls evidenced

Gather implementation and validation evidence for change logging, network restrictions, training effectiveness, account automation, passwordless access, information protection, and cryptographic module choices.

Exit: mandatory KSI evidence is mapped to the package; cryptographic coverage is documented; optional validated-module adoption is decided and evidenced if adopted.

3. Communication and incident response exercised

Establish reliable FedRAMP communications and exercise incident evaluation, reporting, and procedure review.

Exit: inbox delivery and emergency-action handling are tested; reportability and final-report workflows are demonstrated; initial/ongoing report recommendations have adoption decisions and evidence where adopted.

4. Vulnerability management workflow validated

Connect scoped resources to vulnerability detection, evaluation, response targets, and incident escalation.

Exit: mandatory detection coverage is evidenced; recommended detection/evaluation/response cadences have documented adoption decisions; adopted schedules and deadline calculations are tested. Optional internet and non-internet incident triggers have explicit dispositions and do not replace mandatory incident evaluation.

5. Certification data sharing ready

Publish offering information and establish the trust-center access and agency-denial workflow.

Exit: public human-readable/JSON information and trust-center access are verified; denial notification handling is documented; availability reporting and per-service materials have adoption decisions and evidence if adopted.

6. Ongoing reporting and maintenance ready

Prepare ongoing certification reporting, public next-report dates, package maintenance, and adopted historical metrics/activity exports or quarterly reviews.

Exit: a real or example OCR is complete; reporting and maintenance responsibilities are assigned; adopted recurring workflows and JSON exports are validated. Optional items may close through a documented decision not to adopt.

7. Certification package reviewed and ready

Assemble the package, reconcile all mandatory evidence and recommended/optional dispositions, and review independent assessment materials and JSON validation.

Exit: the three master checklists are reconciled; package artifacts and evidence mappings are complete; underlying-framework assessment expectations are addressed; optional FedRAMP assessment decisions and any freshness checks are recorded; package review identifies no unresolved required gaps.

This milestone covers readiness of the work currently represented in this project. Final review must also check broader Class A eligibility and application obligations noted in FRC-CLA-MFR: Address the 23 mandatory Class A certification rules. Completion does not itself mean FedRAMP certification has been awarded.

These rules are MAY options for Class A. Each sub-issue should record an adoption/applicability decision, then link implementation and evidence if adopted.
